# Converge: Miami artists, found by asking

A demo web app where artists find each other with a single prompt. Every artist gets an expressive link-in-bio profile, and a Lovable-style search box lets you ask for exactly who you need ("upbeat artists to remix my single", "a muralist for a wall in Wynwood").

## What's inside

- **Prompt-first home** with discipline filters and example requests.
- **Link-in-bio profiles** with eight looks (Poster, Gallery, Darkroom, Cinema, Flow, Editorial, Stage, Blueprint), defaulted by discipline and selectable during onboarding.
- **Onboarding modeled on Luma's flow**: claim a handle, pick your craft, profile (photo, name, bio), links, then a look, with a live phone preview. Demo profiles are stored only in the browser's `localStorage`.
- **Tap-to-talk search**: the mic next to the search box dictates your request and searches when you pause, following the gallery's voice flow (tap, speak, ~1.5 s of quiet ends the turn, 25 s cap). Uses the browser's built-in speech recognition (Chrome, Edge, Safari), so there's no key or server; the button hides where it isn't supported.
- **Search that understands vibes**: mood words like *upbeat*, *mellow*, *heavy* and *romantic* map to genres (house, reggaeton, jazz, soul…).
- **Reach out** panel showing only publicly published contacts (official email listed on Wikidata, Instagram DM, official website, X) plus a suggested intro.

## Data

`src/data/artists.json` is generated by `pnpm data` (`scripts/build-artists.py`) from public sources:

- **Wikidata** (CC0): people linked to Miami (born, lives or works there) with an artistic occupation and an English Wikipedia article; their official links and published email.
- **Wikipedia** (CC BY-SA 4.0): short bios.
- **Wikimedia Commons**: photos, with author and license credited on each profile.
- **MusicBrainz**: genres for musicians.

Profiles are real public figures; the demo isn't affiliated with or endorsed by any of them.

## AI search

- **On-device (this Mac)**: `pnpm bridge` starts a local server on `127.0.0.1:8787` that calls Apple's Foundation Models framework (macOS 26+, Apple Intelligence enabled). It extracts the request's disciplines, keywords and vibe, and writes the summary. Only the query and the names/taglines of the top matches are sent to the on-device model.
- **Everywhere else**: if the bridge isn't reachable, the app falls back to built-in local intent parsing and ranking. No API keys or paid calls.

To let a deployed copy reach the bridge on your own Mac, start it with `CONVERGE_ORIGINS=https://<your-site> pnpm bridge`.

## Develop

```sh
pnpm install
pnpm dev        # http://localhost:5173
pnpm bridge     # optional, on-device AI
pnpm verify     # lint + typecheck + build (runs in CI)
```

Deployed to Cloudflare Pages (`dist/`, SPA fallback via `public/_redirects`).
